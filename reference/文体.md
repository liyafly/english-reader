# 文体

长难句、词的用法、语法、自测对所有文体都一样。随文体变的是读前和理解（两种模式的读前、轻读的理解题），以及精读的赏析和写作。文体没指定时，自己判断，写进计划。

## 读前和理解

| 文体 | 读前的背景写什么 | 理解题问什么 |
| --- | --- | --- |
| 小说、故事 | 上一单元结束时的处境；时代和地方的常识（货币、交通、阶层） | 人物为什么这样做；从一句话看出人物的态度或关系；言外之意 |
| 新闻 | 发表时间、地点、涉及的机构和人；事件此前的情况 | 报道的核心事实是什么；谁说的、依据是什么；哪些是记者的判断 |
| 演讲 | 谁、什么时候、在哪里、对谁讲 | 讲者要听众做什么或相信什么；用了什么理由 |
| 评论、随笔 | 作者是谁、在哪里发表、回应的是什么 | 作者的观点；拿什么支持；让步在哪里 |
| 科普、说明文 | 讲的是哪个领域的什么问题 | 核心概念是什么意思；因果链是怎样的 |

读前不概括非小说作者的观点，也不透露小说本单元的情节；这些是读者自己读出来的，理解题再问。

## 赏析和写作（精读）

| 文体 | 赏析讲什么 | 写作学什么 |
| --- | --- | --- |
| 小说、故事 | 叙述视角、叙述者插话、人物怎么立起来、讽刺、节奏、声音 | 用动作写状态、长短句搭配、感叹句、细节清单 |
| 新闻 | 标题和导语、消息来源怎么交代、被动和名词化、哪些词带立场、引语放在哪 | 写导语、转述别人的话、交代来源 |
| 演讲 | 称呼、排比、反问、设问、重复、怎么收尾、为“听”安排的节奏 | 排比句、三项并列、口语里的停顿和强调 |
| 评论、随笔 | 观点在哪、证据是什么、怎么让步再反驳；随笔看口气、讽刺和典故 | 摆出两种看法、让步句、过渡词 |
| 科普、说明文 | 怎么下定义、举例、讲因果、怎么把术语说清楚 | 定义句、举例句、比较句、因果句 |

## 赏析的要求，各文体都一样

- 每个点引一句完整的原文，给译文，先说哪个词、哪个结构在起作用，再说它的作用。
- 手法第一次出现时给英文名，用 `术语.tsv` 的对照。表里没有的新手法，先加进表里再用。
- 区分原文明示的和据线索推断的。推断要写出依据。
- 不提后面单元的情节，也不写“后面会再出现”。伏笔（foreshadowing）只有在用户说已经读完或不在意时才讲。

## 各文体的注意事项

**小说、故事**
- 区分人物的话和叙述者的话。叙述者跳出来对读者说话（时态换成现在时）是常见的赏析点。
- 动物、拟人化的角色，代词照原文：原文用 he 就译成“他”。

**新闻**
- 消息来源是重点：said、according to、told reporters、claimed 各有分寸，可以出词条。
- 被动和名词化常用来隐去施动者，赏析时指出“谁做的没说”。
- 时效性：讲解里不补写原文以后的新进展，需要背景时在读前或前言里交代原文发表时的情况。

**演讲**
- 演讲是给人听的。节奏、重复、停顿比书面文章重要，赏析讲“念出来是什么效果”。
- 读前或前言交代场合：谁、什么时候、对谁讲。

**评论、随笔**
- 观点由理解题问出来；精读时第一个赏析点可以用一句话说出作者的观点，后面的赏析围绕它。
- 讽刺和典故要说明出处；查不到出处的不讲。

**科普、说明文**
- 术语给英文原词和中文通行译名，不自己造译名。
- 原文里的数据照抄，不换算、不更新。

## 赏析关掉时

- 精讲句里的「赏析」一项和「## 赏析」一节都不出。
- 自测里的赏析题换成理解题：问原文说了什么、为什么，答案引原文。
- 写作一节照旧（除非也关掉）。
