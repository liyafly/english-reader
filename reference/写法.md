# 讲解的写法（共用）

写讲义的人（或模型）照这份和所做模式的那一份写：轻读单元看 `轻读.md`，精读单元看 `精读.md`。长难句和卡句两种模式都写成句子块，看 `句子.md`。读者水平怎么落到内容上看 `水平.md`，文体看 `文体.md`，数量和长度上限只写在 `scripts/rules.json`。写之前先通读对应模式的样板：`demo/源稿/第02章.md`（轻读）、`demo/源稿/第01章.md`（精读）。

这套规范是第三版，新项目的 `设置.json` 写 `"format": 3`。没有 `format` 的是第一、二版的项目：check 照旧按旧规则查；续写时照这个项目已有的讲义写，不擅自升级，要升级先问用户。

## 两种模式

每个单元是轻读或精读，由 `设置.json` 定：单元自己的 `mode`，没写就用 `default_mode`。新项目默认轻读。

| | 轻读 | 精读 |
| --- | --- | --- |
| 读者怎么用 | 先看读前，再读原文，读完做读后：先拆长难句，再答题 | 先看读前，再读原文，读完看讲解 |
| 目的 | 读得下去，读懂主线，练拆长句，认得反复出现的词 | 读懂长句，学会用词，能照着写 |
| 栏目 | 读前、长难句、理解、词的用法、复述 | 读前、长难句、词的用法、语法、赏析、写作、自测 |
| 长难句 | 精讲句加练习句 | 全是精讲句，可以加怎么拆、句型、延伸、赏析 |
| 篇幅 | 读前半页到一页；读后有页数上限（A5，`v3.light.pdf.post_pages`） | 不限页数，按数量规则 |

两种模式的末尾都可以有 `## 卡句`。

两种模式共用：

- 长难句和卡句写成同一种句子块：原句、结构标签、试、断句表、答，精讲句再加卡点和译。写法见 `句子.md`。
- 主语、谓语、从句这些术语直接用，不从零讲。前言里有一页“语法术语”，读者不明白时自己翻。
- 每个词条都要让读者知道：这个要会用，还是读懂就行。
- 引了原文就给译文。读者不该因为看不懂例句而学不到用法。

## 读前（两种模式都有）

```markdown
# 第 N 章讲解

## 读前

背景一段。

- **人名**：身份
- **人名**：身份

### 本章的词

- **word** /ipa/ v. 本章里的意思
- **phrase** phr. 本章里的意思
```

- **背景**：一段。只写此前单元讲过的内容和时代常识，本单元的情节一句不写。小说写到上一单元结束时的处境就停；非小说写发表时间、场合、人和机构，不概括作者的观点。
- **人物**：只列本单元首次出场的，身份写到出场时读者已经知道的程度，不透露他后面做什么。没有新人物就不写这个列表。
- **本章的词**：每个词一行，词、音标、词性、本章里的意思，不给例句。选词条件：本单元里反复出现（`profile.py` 的读前词候选）；高于读者水平，或未定级但读者多半不认识；前面单元的读前没列过。意思按本章的用法写，不照搬词典的第一个义项。
- 读前是读原文之前看的，所以不引原文、不出题、不讲句子。

## 卡句（两种模式都可以有）

用户读的时候卡住的句子，记在项目根目录的 `卡句.txt`；用户在对话里贴的，有项目时先追加进去。写读后时，本单元的卡句先占长难句的名额；名额不够的，或读后写好以后才来的，写在单元末尾的 `## 卡句`。

- 句子块怎么写、标记怎么影响讲法，见 `句子.md` 的「卡句」。
- 单独编号，按原文顺序，不占数量上限，不算篇幅，不影响“句 N”的编号。
- 用户贴的引号、撇号、空格常和底本不同。用 `build.py stuck` 在原文里找到这一句，引文照底本抄。
- 原文里找不到，或者没有项目，就只在对话里用句子块讲，不写进讲义。
- 第三版没有 `## 补充句`，写了 check 会报，改成 `## 卡句`。

“章”换成 `设置.json` 里 `unit` 的叫法（章、部分、篇）。单篇文章的一级标题写 `# 讲解`。

## 脚本会检查的

`python3 scripts/build.py check 项目目录` 的结果分两种：

- **问题**：必须改到 0 个。
- **提示**：靠估计得出的，比如词的级别、排出来大约几页。逐条看，有理由不改的，在 `制作记录/计划与检查.md` 的「检查和审稿记录」里记一句。

两种模式都查：

- 栏目的名字和顺序，各模式的栏目见 `轻读.md`、`精读.md`。第一版的项目（`设置.json` 里没有 `default_mode`）按精读查，读前可以没有。
- 读前：本章的词每行是 `- **word** /ipa/ pos. 释义` 或 `- **phrase** phr. 释义`；和本单元「词的用法」不重复，前面单元的读前列过的也不再列。每个词在本单元原文里出现的次数（按原形算，带连字符的词拆开算，luncheon-basket 里的 luncheon 也算）不够长文 3 次、短文 2 次（见 `rules.json`）是问题；级别不高于读者是提示。
- 词条下面的行只能以这些开头：词典、掌握、原文、译、搭配、辨析、词族、例、注意。每行两个空格缩进。每个词条有词典、原文，一行 `掌握：会用` 或 `掌握：认得`。
- 每一行 `原文：` 后面紧跟一行 `译：`，中间不空行。「长难句」「卡句」以外的每一段 `> 原文`，下面紧跟一行 `译：…`（中间可以空一行）。
- `> ` 开头的行和 `原文：*…*` 里的文字，必须能在本单元原文里逐字找到。省略号会对不上，要引就引连续的一段。所以 `> ` 只用来引原文，自造的句子写在普通行、列表或 `例：` 行里。句子块的断句栏连起来也要和原句一字不差。
- 引号、撇号、破折号照抄原文。自己写的英文一律用弯撇号 ’ 和弯引号 “ ”，不用直引号。断句栏是引文，不查直引号。
- 粗体和斜体里面不能再有星号。斜体只用于 `原文：*…*` 和表格里的引文。
- 长难句从 1 连续编号，按原文出现的顺序，轻读的精讲句和练习句同一套编号；卡句自成一套编号。题目和答案数量相同。
- 数量和长度：规则在 `scripts/rules.json`，按本单元原文的词数分长文和短文（界线是 `counts.short_words`）。轻读的数量看 `v3.light.counts`，精读看 `counts`，句子块的上限看 `v3.sentence`。超了长度就是在绕，删到够用为止。
- 句子块：结构标签、断句表、试和答、注、卡点、译，各查什么见 `句子.md` 的「脚本会查的」。
- 禁用语：`reference/禁用语.txt` 里的说法一律不许出现（译文和顺读栏不查）。
- 修辞和叙事手法的中英对照在 `reference/术语.tsv`。第一次出现写成「中文（English）」，全部单元里同一个英文只对一个中文。
- 语法术语：前言里有「语法术语」表时，讲解用到的语法术语（以 `reference/前言模板.md` 表里列的为准）表里要有，缺了是问题；表里有、讲义一次没用到的是提示。
- 句子结构：前言的 `## 句子结构` 表里要有讲义用到的每个结构标签，缺了是问题；表里有、讲义一次没用到的是提示。
- 卡句：有 `卡句.txt` 时，定位到本单元、讲义里却没讲的句子，一句一条提示。

`python3 scripts/lexicon.py check 讲义` 另查词典：音标、词性、语体标签，以及“会用/认得”的建议。讲解里写了“英式”“正式”“旧式”这类说法、词典里却没有对应标签的，它会标出来。

## 脚本查不了、要自己把关的

**长难句和卡句**
- 选什么样的句子，见 `水平.md`。只是长、没有难点的不选。
- 断句切得对不对、挂得对不对、顺读通不通、卡点和标签准不准，脚本都查不了。要把关的几项见 `句子.md` 的「脚本查不了、要自己把关的」。

**词条**
- 像词典：「词典」行写英式音标、词性缩写和释义。短语没有音标，只写 `phr.` 和释义。缩写只用 n. v. vt. vi. adj. adv. prep. conj. pron. phr. [U] [C] sb sth。
- 音标用 Oxford Learner’s Dictionaries 和国内教材的写法：/æ/、/e/、/eə/、/ɜː/、/aɪ/，词尾的 (r) 不写，g 写成 ɡ。用 `scripts/lexicon.py check` 核对，它会把系统词典、Wiktionary 的另一套写法换算过来再比。读前的词同样核对。
- 词条第一行讲用法：后面接什么、和直觉哪里不一样。不要把词典释义再说一遍。
- 「辨析」写易混词；「词族」写派生词；「例」给自造例句；「注意」写一处具体的坑。
- 词条不重复精讲句已经讲透的内容。同一个点不要既当句子又当词条。词条要讲的词，句子块里不再注。
- 熟词生义优先：读者以为认识、其实在这里是另一个意思的词（row 读 /raʊ/ 是吵闹，make 是“成为”），比生僻词更值得讲。

**不剧透**
- 讲义只用本单元和前面单元的内容。后面单元的情节不提，“后面会再出现”“第 N 章会……”这类话也不写，除非用户说已经读完或不在意。

**译文和事实**
- 译文自己译，不抄现成译本。人名、地名用通行译名，在前言里列一次。
- 明确区分“本句结合上下文的解释”与“一般语法规则”。赏析区分人物的说法、叙述者的说法、原文明示的和据线索推断的。
- 仿写句、例句、复述参考和自测题自己造，不能冒充原文。

## 三条硬规矩

这三条是从审稿查出的真实错误里总结的，写之前对照一遍。

1. **数得出来的话要数。** “上一句”“前一段”“四个词”“第三次出现”“本章出现四次”，写之前回原文核对。
2. **“只”“一律”“几乎都”“没有一个”“不能”这类话，查不到依据就不写。** 语法和用法的断言拿不准就不写。“旧式”“正式”“英式”“只用于”这类标签要在词典里看到才写（`lexicon.py entry 词` 会列出词典给的标签）。音标拿不准的词不要选。
3. **概括情节的话，逐句回原文找出处。** 读前的背景、赏析和答案里说“谁做了什么、说了什么、为什么”的句子，写完一句一句在原文里找到对应的段落，找不到就删或改。凭印象概括最容易错，审稿查出的事实错误多在这里。

## 口气

- 文字写短，一句一个意思，不用比喻和感叹。
- 不写防御性的话。规则直接说常见情况；真有例外，给一个例句。
- 开门见山。不写导语、使用说明、总结，不写“先自己想一想”这类引导语。每个单元从读前的背景直接开始。
- 关于“其他读法”“答案只是一种”这类说明，在前言里说一次，单元里不写。

## 坏写法和好写法

都是审稿时真实改掉的例子。精读专有栏目（延伸、语法、赏析、写作、自测）的例子在 `精读.md`，句子块（断句、顺读、指代）的在 `句子.md`。

| 栏目 | 坏的 | 好的 | 毛病 |
| --- | --- | --- | --- |
| 卡点 | 这句语法不难，难在语气 | `of that description`：description 在这里是“那一类”，不是“描述” | 没指出具体哪几个词 |
| 卡点 | `object to` 的 to 是介词，后面接名词或 doing | `it was resolved` 容易读成“问题解决了”；这里 resolve 是“（开会）决定” | 讲的是一般规则，不是这句的读法障碍 |
| 词条首行 | 表示唯一的，在这里修饰 object | 只放在名词前面，不说 The reason is sole | 复述词典，没讲用法 |
| 词条首行 | 作及物动词是“行使”，和“锻炼”无关 | 宾语决定意思：权利、权力是“行使”；身体部位或动物是“锻炼” | “无关”是没核实的断言 |
| 赏析 | 第 3 章鼹鼠一个人走进了野树林，这里先埋下伏笔 | （删掉）只讲本章：河鼠不愿多谈野树林，一句 Don’t ever refer to it again 就把话头堵住了 | 剧透后面的章节 |
| 规则 | 须结合语境判断，不能一概而论 | 主句是现在时才这样读；主句是过去时，看上下文 | 防御性的话，不教东西 |
| 术语 | 一处把自问自答叫设问（rhetorical question），另一处把不需要回答的问句也叫 rhetorical question | 不需要回答的是反问（rhetorical question）；自问自答是设问（hypophora） | 同一个英文对了两个中文 |
| 词条 | interfere with sb 是“招惹某人”，掌握：会用 | 本章 interferes with him 是“招惹他”；今天的英式英语里 interfere with sb 多指猥亵，说“招惹”用 bother sb。掌握：认得 | 没查词典的现代用法，教会用会出错 |
| 译 | 没人敢招惹他（原文 Nobody interferes with him） | 没人招惹他 | “敢”是从下一句推出来的，译进了原文 |
| 读前 | 鼹鼠学划船时把船弄翻了 | 鼹鼠抢过桨来划船，把船弄翻了 | 凭印象概括上一章，没回原文核对 |
| 理解答案 | 他想家，后悔出来了 | 他想家，想他的河，嘴上不提，心里一直放不下 | 把推断写成了原文的意思 |
| 复述参考 | Toad has taken up a new fad | Toad has taken up a new hobby | 参考用了高于读者水平、讲义又没讲过的词 |

## 前言

`源稿/前言.md` 排在合订本的前部。开头两段是出处说明和缩写；后面每个 `## 标题` 是单独的一页。前言模板在 `reference/前言模板.md`：

- 出处：作者、篇名、出版年份、用的哪个底本；“译文和讲解为自写，AI 协助；例句、复述参考和自测题不是原文；赏析是一种读法，有原文依据的别的读法也对”。按讲义里实际有的栏目写：全是轻读的书不提仿写、自测、赏析。加一句回读：“拆完的句子，按正常速度再读两三遍。”这一段会印在 PDF 的“怎么用”页上，写短，否则那一页会挤成两页。
- 缩写。
- 怎么用：读前 → 原文 → 读后（精读单元是讲解）。
- 语法术语表（B1 及以下必附，B2 以上可以不附）。
- 句子结构表：本书用到的结构标签，每个一行，写意思和一个自造例句。各档水平都附。
- 人名和译名：只列译名，不写人物后来的情节。历史对应、新闻的来龙去脉、演讲的场合，用得上才写，同样不剧透。
