# 审稿任务书

给独立审稿的子代理用。写讲义的和审讲义的分开：审稿的人没参与写，只拿到下面这些材料。把整份任务书连同材料路径交给审稿代理，并写明这个单元是轻读还是精读。

## 材料

- 讲义：`讲义/第NN章.md`（以及 `讲义/前言.md`，第一个单元时一起审）。多个轻读单元可以一次交给同一个审稿人
- 原文：`原文/第NN章.txt`；多单元时，前面单元的原文和讲义也给，用来核对“上一章”这类说法和读前的取材
- 写法规范：`reference/写法.md`、`reference/句子.md`，加上所审模式的 `reference/轻读.md` 或 `reference/精读.md`；`reference/水平.md`、`reference/文体.md`；结构标签的清单 `reference/结构标签.tsv`
- 设置和计划：`设置.json`（读者水平、文体、各单元的模式）、`制作记录/计划与检查.md` 的「## 计划」和台账
- 卡句：项目里有 `卡句.txt` 时一起给，附上 `build.py stuck` 的输出（每句的标记、句内高于水平的词）
- 词典：`scripts/lexicon.py check 讲义 --level 水平` 出词典行核对表；`scripts/lexicon.py entry 词` 看单个词的音标、词性、标签和来源

## 先跑脚本，脚本查过的不用再查

审之前在项目目录跑 `build.py check` 和 `lexicon.py check`。下面这些脚本已经查过，不用再查：引文是否逐字、断句栏连起来是否等于原句、缩进的层数、粗体是否只在顶格行、句子块该有的项有没有、标签是否在清单里、注和答的格式和长度、数量和长度、读前的词出现的次数和格式、读前的词和词条是否重复、理解答案的句数、复述参考的句数和词数、语法术语和结构标签是否在前言表里、禁用语、直引号。脚本报的「提示」（级别、估计页数、句子里没注的超纲词、句长、主标签的种数、复述参考里的超纲词、词典里找不到的标签）要看一眼，判断讲义该不该改。

逐句、逐条、逐题地查，每一项都要回原文或词典核对，不凭印象。

## 句子块（两种模式都审）

长难句和卡句逐句查，对着原句和 `句子.md`：

1. **断句。** 切点是不是意群的边；顶格行连起来读，是不是主句的骨架；缩进行挂的对象对不对（修饰谁，就挂在谁下面）；粗体是不是主语的中心词和谓语动词。
2. **顺读。** 每块是不是只译这一行，有没有把后面行的意思提前；有没有调语序；和「译」的意思是否一致。
3. **指代。** 句里的 it、this、that、which、they、one、so 指什么，讲义（顺读的括号、卡点、答）说对了没有。
4. **标签。** 主标签是不是这句最挡路的一处；易混的两个标签有没有分错（见 `句子.md`）。
5. **试和答。** 问题是不是具体；答案是不是唯一。
6. **注。** 释义是不是本句的意思，不是照搬词典的第一个义项。
7. **卡句。** 讲法和标记对不对得上：词都认识的，卡点写结构或指代，熟词生义确是最挡路的一处才写词义；有生词的，生词注了；注完就通的，标签是词汇，没有试和卡点。
8. **前言的句子结构表**（第一个单元时）。自造的例子对不对，加粗的是不是这个标签说的地方。

## 轻读审这几项

1. **关于原文的事实是否属实。** 读前的背景、理解题的答案里概括情节的每一句，回原文找到对应的段落：人物做了什么、说了什么、为什么，原文是不是这样写的。“上一章”“两晚”“五次”这类数字逐个数。凭印象概括最容易错，这一项最要紧。
2. **有没有剧透。** 讲义里任何地方提到后面单元的情节，或者写“后面会再出现”“第 N 章会……”，都报。用户说过已经读完或不在意的除外（看 `制作记录/计划与检查.md` 的计划）。
3. **读前守不守界线。** 背景有没有透露本单元的情节；人物的身份是不是出场时读者已经知道的；非小说有没有替作者概括观点。本章的词的释义是不是本章的意思。
4. **理解题。** 读过一遍、不回翻能不能答出来；有没有考数字、清单、次要情节的先后；没读懂的人会不会答错；答案有没有把推断写成原文的意思，引的原文能不能支持答案。
5. **长难句。** 精讲句是不是挡住主线理解的句子，练习句是不是词不难的长句；卡点是不是具体的一处；译文忠不忠实（漏译、错译、把推断译进去）。句子块的各项按上面「句子块」一节审。
6. **词条。** 首行是不是在讲用法而不是复述释义；用法和标签的说法有没有依据（“只”“不能”“英式”“旧式”这类话查词典）；“会用/认得”是否符合 `水平.md`。
7. **复述。** 参考是否只复述本单元的主线，事实对不对，英文对不对；提示词是否取自读前的词和词条。

## 精读审这几项

1. **自写的英文对不对。** 仿写、例句、对照、参考答案里的英文：语法、搭配、用词是否地道；英式拼写是否统一。
2. **语法断言有没有说过头。** “只”“一律”“不能”“总是”“旧式”“只用于”这类话，查词典或通行语法书，查不到依据就提出来。规则和所举的例句是否对得上。
3. **译文忠不忠实。** 有没有漏译（尤其是讲解要用到的那个词）、错译、把推断译成了原文的意思。
4. **关于原文的事实是否属实。** “上一句”“前一段”“出现了几次”“几个词”这类说法，逐个回原文数、找。读前的背景、赏析和答案里概括情节的句子，逐句回原文找出处。
5. **有没有剧透。** 同轻读第 2 项。
6. **读前守不守界线。** 同轻读第 3 项。
7. **前后是否一致。** 同一个词、术语、人名的译法；句号、章号的回指；读前、长难句、词条、语法、赏析之间有没有重复讲同一个点，或说法互相矛盾。
8. **是否违反写法规范。** 卡点是不是具体的一处；「怎么拆」是不是只写了断句表说不清的、有没有把「答」再写一遍；词条首行是不是在讲用法而不是复述释义；有没有防御性的话、套话、论文腔、比喻；“会用/认得”是否符合 `水平.md`。句子块的各项按上面「句子块」一节审。
9. **自测答案对不对。** 按题目字面去做一遍，答案是否唯一正确；题目有没有考没讲过的东西，有没有要求用“认得”的词造句；回头看是否只考前面精读单元讲过的内容。
10. **赏析。** 有没有指出具体的词；有没有拔高；区分人物、叙述者、明示和推断。

两种模式都核对 `lexicon.py check` 的结果：标“不一致”的逐条查；标“参考”“未核对”的，在报告里说明没能核对。

## 怎么报

按严重程度分三级，最严重的在前：

- **错误**：事实错、语法错（包括断句挂错、指代说错）、答案错、音标错、剧透。必须改。
- **应改**：说过头、译文不准、违反写法规范、前后不一致、读前越界。
- **可改**：可以更好，但现在也不算错。

每一条写成：

```
### 编号. 文件 · 位置（读前 / 理解 N / 句 N 断句 / 句 N 顺读 / 句 N 卡点 / 卡句 N 译 / 词条 X / 赏析小标题 / 自测 N / 复述 / 前言）
- 原文：讲义里有问题的那一句，照抄
- 问题：错在哪，一两句
- 依据：原文里的句子，或词典条目（写明来源）
- 改为：可以直接替换进去的文字，符合写法规范
```

没有依据的不报。只是口味不同的不报。最后一行给出三级各几条。

## 审稿以后

写讲义的人逐条判断：采纳的改掉，不采纳的在 `制作记录/计划与检查.md` 的「## 检查和审稿记录」里记一句理由。改完重跑 `build.py check`。“错误”级的问题，每个单元改完后应为零。

轻读审一轮；改动十条以上时，再请一个新的审稿人只看改过的行和前后的句子。精读改动多的（十条以上），再请一个新的审稿人按本任务书审一轮。第二轮特别留意上一轮补进去的句子：和前后文接不接得上，“三点”“两处”这类数字和下面列的条数对不对，新加的规则和本句的例子对不对得上，有没有和同一条里别的说法矛盾。
